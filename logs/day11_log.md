## 概念1：采样
>在扩散模型里面，采样在描述：根据一张完全被打乱（全是噪声）的分子图中一步步去噪，生成一个完整的分子图的过程。
打乱的分子图————>完整的分子图

在DAY10中对每条谱数据只进行了一次采样，所以只生成了一个候选分子；而day11要求生成更多的候选分子，所以要对每一条谱数据进行多次采样。
>**DAY10**
质谱 → 编码器 → 条件向量 → 随机噪声 → 去噪500步 → 生成1个分子
**DAY11**
质谱 → 编码器 → 条件向量
         ↓
   随机噪声1 → 去噪 → 分子1
   随机噪声2 → 去噪 → 分子2
   随机噪声3 → 去噪 → 分子3
   ...
   随机噪声30 → 去噪 → 分子30
## 为什么同一条谱能生成不同的分子？

因为扩散模型的生成过程**包含随机性**：

| 生成过程中的随机因素 | 影响 |
|----------------------|------|
| 起始噪声（A_T）不同 | 每次从不同的随机图开始去噪 |
| 去噪过程中的随机采样 | 每一步有概率随机选择不同的边 |

所以，即使输入条件完全相同（同一条质谱），每次生成的结果也会不同。

**这正好对应了论文里说的“一对多问题”**：同一条质谱可以对应多个合法的分子结构。

## 为什么论文里要做多候选采样？

因为**单次采样可能运气不好，正好生成了“不像”的那一个**。但如果采样足够多次，总有一个候选可能接近真实分子。

在论文的评测里，他们报告的不是“随机一次采样的结果”，而是 **Top-1、Top-5、Top-10 的最佳结果**——也就是从多个候选中挑最好的那一个来算相似度。

### Cell2：def binned_spectrum(...)
>对质谱数据进行统一规范化。就是把每一条数据变成固定长度的向量。
注：这里和day9的做法是一样的。
>>重要参数：
bin_size=1.0；（每一个格子能覆盖多大的m/z的范围）限制横轴每一个格子的宽度；
max_mz=1000;(截取质谱数据的范围上限。
在代码里，max_mz=1000，意思是：
“我只关心 m/z 在 0 到 1000 之间的峰，超过 1000 的直接忽略。”)
**size(向量的位数)=max_mz/bin_size;**
>
1.如果同一个位置发生了强度的冲突，取强度最高的那个峰的数值进行该位置的填写；
2.归一化处理的必要性（vec=vec/vec.max()）
| 原因 | 说明 |
|------|------|
| **统一数值范围** | 不同质谱仪的强度量纲可能不同，归一化后都变成 0~1 |
| **方便神经网络处理** | 神经网络喜欢输入在 0~1 或 -1~1 之间 |
| **消除仪器差异** | 不同仪器测出的绝对强度不同，但相对强度是稳定的 |
>
>3.in zip(list1,list2):
zip把两个列表变成一对一对的（元组），每次循环同时取一个 m/z 和它对应的 intensity。
**eg:**
```python
mz_list = [194.12, 212.13, 730.42]
inten_list = [1.0, 0.58, 0.56]
```

`zip(mz_list, inten_list)` 做的事情是：

```python
zip对象 → 相当于 → [(194.12, 1.0), (212.13, 0.58), (730.42, 0.56)]
```

>然后 `for mz, inten in zip(...)` 每次循环取一对：

| 循环次数 | `mz` | `inten` |
|----------|------|---------|
| 第1次 | 194.12 | 1.0 |
| 第2次 | 212.13 | 0.58 |
| 第3次 | 730.42 | 0.56 |

>4.语法错误：
if mz in (0, mz_max): 是错误的
你写的这个条件的意思是：
“只有 m/z 正好等于 0 或正好等于 1000 的峰才被保留，其他全部丢弃。”
5.逻辑错误：idx=int(mz/bin_size);#错误：这里是bin_size不是size
当前位置/格子宽度表示自己落入的区间位置
